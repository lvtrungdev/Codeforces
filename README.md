# Codeforces Solutions

Bộ sưu tập các bài giải Codeforces bằng C++.

## Cấu trúc thư mục

```
{problem-id}-{problem-name}/
└── solution.cpp
```

## Template

Sử dụng `template.cpp` để bắt đầu code bài mới.

## Danh sách bài đã giải

| Problem ID | Tên bài | Chủ đề |
|------------|---------|--------|
| 43A | Football | Implementation, Map |
| 230B | T-primes | Math, Sieve, Number Theory |
| 750A | New Year and Hurry | Greedy, Math |
| 1717A | Madoka and Strange Thoughts | Math, Number Theory |

## Compile & Run

```bash
g++ -std=c++17 -O2 solution.cpp -o solution
./solution
```
